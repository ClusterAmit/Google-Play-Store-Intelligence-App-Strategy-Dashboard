# Google Play Store Intelligence & App Strategy Dashboard

## Project Overview

An interactive Tableau dashboard designed to analyze the Google Play
Store app ecosystem. It evaluates app distribution, install volume,
ratings, reviews, app size, pricing, monetization, and user sentiment to
help identify market opportunities and app strategy insights.

## Dashboard Objectives

-   Understand the overall size and composition of the app catalog.
-   Identify app categories driving the highest install volumes.
-   Compare category popularity with app quality using ratings and
    installs.
-   Explore the relationship between app size and install volume.
-   Assess pricing tiers and rating patterns to understand monetization
    opportunities.
-   Compare positive, neutral, and negative review sentiment across
    rating groups.

## Dashboard Features

### 1. App Category Performance

Ranks app categories by total install volume and displays average
ratings to compare category reach and quality.

### 2. Category Quality vs. Popularity Matrix

Uses a bubble chart to compare category-level installs and average
ratings. Bubble size represents relative category scale, helping
distinguish high-reach categories from smaller or lower-rated segments.

### 3. App Size Impact on Installs

Compares average install volume across app-size buckets to explore
whether app size is associated with differences in adoption.

### 4. Monetization & Price Elasticity

Compares average user ratings across price tiers, including free apps.
This provides an exploratory view of rating patterns across pricing
segments; it does not establish causal price elasticity.

### 5. User Review Sentiment

Shows the distribution of positive, neutral, and negative review
sentiment across app rating tiers.

## Interactive Filters

Users can filter the dashboard by: - Category - App Type - Content
Rating

All dashboard views are designed to respond to the selected filters.

-   **Data Analysis:** KPI design, category comparisons, segmentation,
    and trend interpretation
-   **Data Visualization:** Bar charts, bubble chart, stacked bars, and
    KPI cards

## Business Questions Addressed

-   Which app categories attract the highest install volumes?
-   Which categories combine strong popularity with high average
    ratings?
-   How does average install volume vary by app-size group?
-   How do ratings differ across app pricing tiers?
-   How does review sentiment vary across rating groups?

## How to Use

1.  Open the Tableau workbook or published dashboard.
2.  Use the Category, Type, and Content Rating filters at the top.
3.  Review the KPI cards for a high-level summary.
4.  Explore each chart to compare category performance, pricing
    segments, app sizes, and review sentiment.
